Интсрукция по запуску:
1) Колинровать репозиторий через git clone https://github.com/Andrecks/jetland_XLSX-

2) Создать и активировать виртуальное окружение python -m venv venv (версия 3.10.7) активировать venv\Scripts\activate (venv\bin\activate для linux)

3) Установить зависимости pip install -r requirements.txt

4) Применить миграции python manage.py migrate

5) Запустить тесты python manage.py test

6) портировать рассылки из XLSX-файла
   python manage.py import_mailings sample_mailings_import.xlsx

Пример запуска с параметрами:
python manage.py import_mailings sample_mailings_import.xlsx --batch-size 500 --workers 4 --min-delay 5 --max-delay 20

Параметры команды
--batch-size — размер пачки для пакетной вставки в БД;
--workers — количество потоков для имитации отправки писем;
--min-delay — минимальная задержка отправки письма в секундах;
--max-delay — максимальная задержка отправки письма в секундах.


Лог сохраняется в
-консоль;
-файл mailings.log в корне проекта.



Что покрывают тесты

Автотесты проверяют основные бизнес-сценарии:

успешный импорт корректных строк из XLSX;
подсчёт статистики:
количество обработанных строк;
количество созданных записей;
количество пропущенных записей;
количество ошибочных строк;
пропуск строк с невалидными данными, например:
некорректный email;
пустой external_id;
ошибку при отсутствии обязательных заголовков в XLSX-файле;
пропуск записей с уже существующим external_id;
успешную имитацию отправки письма с переводом записи в статус sent.
